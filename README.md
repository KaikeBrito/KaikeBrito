## 🚀 Sobre Mim

Desenvolvedor **Full-Stack** no 9º semestre de Ciência da Computação pela UNIFOR, movido por uma visão de engenharia limpa e disruptiva. Minha trajetória combina a construção de arquiteturas robustas de software (focando em transições de monólitos para microsserviços) com a aplicação rigorosa de práticas de **DevSecOps**.

* 💼 **Atualmente:** Estagiário em DevSecOps no Serpro, garantindo segurança contínua no ciclo de desenvolvimento.
* 🔍 **Background:** Experiência no backend do Banco do Nordeste, desenvolvendo sistemas críticos.
* 💡 **Inovação Pessoal:** Utilizo Docker massivamente em meus laboratórios (virtualização com n8n, conteinerização de APIs) para testar os limites das tecnologias que estudo.
