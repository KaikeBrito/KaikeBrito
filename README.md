## 🚀 Sobre Mim

Desenvolvedor **Full-Stack** no 9º semestre de Ciência da Computação na UNIFOR. Atualmente estagiário com foco em **DevSecOps** no Serpro e experiência prévia como desenvolvedor backend no Banco do Nordeste (Java, Spring Boot, DB2). Minha paixão é construir arquiteturas escaláveis (monolíticas e microsserviços), e também desenvolvo projetos pessoais usando Docker (n8n, APIs), .NET, FastAPI, Python (análise de dados, automações), estratégias quantitativas e muito mais. Minha pegada é inovadora, visionária e disruptiva.
